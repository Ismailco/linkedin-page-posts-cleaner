# Security

Please do not report security or privacy issues in a public issue with credentials, cookies, page content, or other sensitive information.

If GitHub private vulnerability reporting is available for this repository, use it. Otherwise, open an issue with a minimal description that does not include secrets and ask for a private contact channel.

Page Posts Cleaner is intentionally local-first: it has no developer-controlled backend, analytics endpoint, or remote JavaScript dependency. Permission or data-flow changes should be reviewed carefully before they are proposed.
