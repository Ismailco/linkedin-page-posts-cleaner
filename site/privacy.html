Privacy

Privacy policy

Page Posts Cleaner is designed to run locally in your browser. It does not operate a remote service or send extension data to a developer-controlled server.

Last updated: September 20, 2026

What the extension does

Page Posts Cleaner helps company page administrators remove published posts from the supported LinkedIn company admin Page Posts view. It uses the page’s existing controls and only starts when the user starts a session from the extension popup.

Information stored locally

The extension stores configuration values such as delay limits, the session limit, and the current session status in chrome.storage.local. This allows the popup to show progress while a session is running. This information stays in the user’s Chrome profile and is not transmitted to us.

Information we collect

We do not collect, sell, or share personally identifiable information, health information, financial information, authentication information, communications, location, web history, user activity, or website content. Page content may be read and interacted with locally while the user-requested cleanup session runs, but it is not sent to a server.

Permissions

  • activeTab: access the active LinkedIn admin tab when the user starts a session.
  • scripting: run the packaged content script on the supported page.
  • storage: save local settings and session state.
  • LinkedIn host access: limit page operation to LinkedIn, with the content script matched only to the company published-posts admin path.

Third parties and remote code

The extension does not use analytics, advertising, external APIs, remote code, or third-party servers. All JavaScript shipped with the extension is included in its package.

Changes and contact

Material changes to this policy will be reflected on this page. For questions about the extension, please use the project’s GitHub repository issue tracker.

Page Posts Cleaner is an independent extension and is not affiliated with, endorsed by, or sponsored by LinkedIn Corporation.
